VANGUARD - GITHUB PAGES VERSION

1. Upload ALL contents of this folder to the main branch of:
   https://github.com/preview/vanguardbyvelorian
2. Open repository Settings > Pages.
3. Under Build and deployment, set Source to GitHub Actions.
4. Open the Actions tab and wait for Deploy to GitHub Pages to finish.
5. Live website:
   https://preview.github.io/vanguardbyvelorian/

Do not upload node_modules, .next, or out.
